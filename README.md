Automated Repair of DNN using Resilient AI is a deep learning framework designed to improve the reliability, robustness, and adaptability of Deep Neural Networks (DNNs). Traditional neural networks often experience performance degradation due to unseen inputs, data distribution shifts, noisy data, or adversarial conditions. Existing solutions typically require complete retraining, which is computationally expensive and time-consuming.

This project introduces a Resilient AI approach that continuously monitors model behavior, detects failures, localizes faulty components, and performs targeted repairs without retraining the entire network.
